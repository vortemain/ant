# Examples

Small real projects that `ant build` builds with no configuration. The
`verify-adapters` workflow builds each one on Linux and Windows (and the iOS
app on macOS) and runs what comes out of `dist/`.

| Folder | Ecosystem | What lands in `dist/` |
|---|---|---|
| `maven-hello` | Java / Maven | `hello-1.0.0.jar` (runs with `java -jar`) |
| `python-hello` | Python (PEP 517) | the wheel and sdist (in `dist/`, where `python -m build` writes them) |
| `docker-hello` | Docker | the `docker-hello` image (or `image.tar` with `output = "tar"`) |
| `dotnet-hello` | .NET | `Hello/`, the published app |
| `ios-hello` | iOS (Xcode, generated by XcodeGen) | the simulator `.app` |

Try one: `cd examples/maven-hello && ant build`.
