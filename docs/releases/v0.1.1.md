A fix release for JavaScript projects.

## Install or update

Already have Ant? Run `ant upgrade`. New install:

```powershell
irm https://raw.githubusercontent.com/vortemain/ant/main/scripts/install/install.ps1 | iex
```

```bash
curl -fsSL https://raw.githubusercontent.com/vortemain/ant/main/scripts/install/install.sh | sh
```

## Fixed

- **npm, pnpm, and Yarn projects:** `ant build` failed at once when your npm config refers to your user folders, for example pnpm's `Failed to replace env in config: ${APPDATA}`. Ant now passes your user folders and npm/pnpm/Yarn settings to the build, and tokens your `.npmrc` refers to (such as `${NPM_TOKEN}`) reach the build without ever being written to the build plan or shown in logs.
- **pnpm and Yarn:** projects locked with `pnpm-lock.yaml` or `yarn.lock` now build with their own package manager (`pnpm run build`, `yarn run build`), and unchanged builds are reused like npm ones.
