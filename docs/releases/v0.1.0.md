The first public version of Ant: one command builds your project on your own machine, and the rebuild you already did comes back in under a second.

## Install

**Windows (PowerShell)**

```powershell
irm https://raw.githubusercontent.com/vortemain/ant/main/scripts/install/install.ps1 | iex
```

**macOS and Linux**

```bash
curl -fsSL https://raw.githubusercontent.com/vortemain/ant/main/scripts/install/install.sh | sh
```

Or download the file for your system below, check it against `SHA256SUMS`, rename it to `ant` (`ant.exe` on Windows), and put it on your PATH. `ant upgrade` keeps it current.

## What's in 0.1.0

- **`ant build`** detects the project and builds it on every core, with no config: Rust, Android (Gradle), npm (Vite, Next, workspaces), Go, Python, Maven, .NET, CMake, Flutter web, iOS (unsigned), Docker, Tauri and Electron. Deliverables land in `dist/`.
- **Reuse:** nothing changed or switching back to a branch you built before comes back in well under a second (Rust ~30× faster than cargo on a 2019 laptop when switching branches; Android no-change ~20× faster than Gradle).
- **Android:** signed release APK and AAB (`ant build --release`, keys sealed by the OS), `ant install` over USB or by QR code, `ant publish android` to Google Play.
- **`ant preview`:** a live preview on your phone and browser over Wi-Fi; web apps reload on save, Android shows "Update ready".
- **`ant dashboard`:** builds, live logs, deliverables and install-on-phone in your browser.
- **Your own server, optional:** `ant server deploy USER@HOST` sets up a Linux VPS over SSH, `ant build --on NAME` builds there (same OS as your laptop), `ant server ui NAME` opens its web UI. Team servers over HTTPS with single sign-on (`ant login URL --sso`).

## Known limits

- Early preview: interfaces may still change.
- iOS builds are unsigned; App Store upload is not available yet.
- `ant build --on` needs the server to run the same OS as your computer (a Windows laptop cannot offload to a Linux server yet).
- macOS and Linux binaries are not code-signed; on macOS, allow the binary in System Settings → Privacy & Security, or install with the script above.
